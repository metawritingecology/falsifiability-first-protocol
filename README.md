# The Falsifiability-First Protocol for Agent-Produced Evidence

A candidate operating protocol treating unfalsifiability as the primary defect class in agent-produced records, with two null-handling admissibility rules. Not a confirmed component of any system.

The single conceptual document is [FALSIFIABILITY_FIRST_PROTOCOL.md](FALSIFIABILITY_FIRST_PROTOCOL.md). Everything else in this repository is operational scaffolding and does not constitute additional conceptual specification.
